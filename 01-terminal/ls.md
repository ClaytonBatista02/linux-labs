# Comando ls

Lista arquivos e diretórios.

## Exemplos

```bash
ls
```

Lista o conteúdo do diretório.

---

```bash
ls -l
```

Mostra detalhes dos arquivos.  
Permissões do arquivo -- Número de Links -- Proprietário -- Grupo -- Tamanho -- Data/Hora -- Nome do Arquivo

---

```bash
ls -la
```

Mostra inclusive arquivos ocultos.

---

```bash
ls -i
```

Identifica o inode dos arquivos.  
Inode é um número único para identificar arquivos de forma única.

---

```bash
ls -o
```
Identico ao formato do -l, porém, não mostra a coluna de -- Grupo --

---

```bash
ls -r
```

Para visualizar de forma reversa.


## O que aprendi

- `-l` mostra permissões
- `-a` mostra arquivos ocultos
- É um dos comandos mais utilizados no Linux.
